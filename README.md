## Добро пожаловать
Я **Инженер по ИИ автоматизациям** с опытом интеграции AI-технологий в бизнес-процессы.  
*Моя специализация — интеграция нейросетей в бизнес-процессы через API, управление данными и создание автоматизаций рабочих процессов для оптимизации операций.*
Мои навыки:
- **Нейронные сети**: Модели и агенты для работы с кодом, текстом, аудио и изображениями (в т.ч. GPT, Claude, Gemini, yandexGPT, DeepSeek).
- **Написание и модернизация кода 1С**: с использование команды ИИ агентов, в кратчайшие сроки, с тестированием кода, документацией и инструкциями.
- **Интеграция ИБ 1С с различными системами**: Опыт интеграции 1С через HTTP-сервисы и API - в т.ч. организация обменов данным между различными информационными базами, с ГИС, организация обменов с онлайн оборудованием,   
- **Интеграция различных приложений через API**: Внедрение ИИ в бизнес-процессы: распознавание документов (vision), n8n, веб-приложения, чат-боты, сайты и корпоративные порталы, дашборды.
- **Создание и поддержка инфраструктуры для автоматизаций**: рабочие облачные серверы с автоматизациями для вас с нуля - установка Ubuntu, контейнеров, баз данных и других необходимых средств, написание кода для автоматизаций, его тестирование и документирование, резервное копирование и версионирование в git.
- **Создание баз знаний**: оцифровка и векторизация данных в любых форматах, внесение их в БД, организация RAG- и гибридного поиска по БД. Создание умных агентов и продавцов.
- **Управление проектами**: Сопровождение проектов с интеграциями и автоматизациями на основе ИИ и оптимизация затрат.
- **Передача разработанных средств заказчику**: облачной инфраструктуры, кода, баз данных, документации, инструкций, логинов-паролей и пр.

- В этом репозитории представлен пример создания на Python ИИ Телеграм-бота с помощью Gemini API
